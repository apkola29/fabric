FINDINGS

F1. Low. `toolchain_catalog.check_against` misses stale `PROTECTED_REVIEWED` entries when the server ID is unknown, when `tools.from` is `"none"`, or when the tool is also flagged in `server["flagged"]`, and allows duplicate/conflicting tool references across `flagged` and `knowledge`.
- File and line: `scripts/toolchain_catalog.py` lines 458–476 and 495–498 (`check_against`).
- Quote: `if server is not None and name not in`
- Details:
  1. In `check_against` lines 495–498, if `sid` in `PROTECTED_REVIEWED` does not exist in `catalog["servers"]`, `server is None` and no problem is reported (while `test_CatalogTests_extract.py` line 460 raises an unhandled `StopIteration`). If `server["tools"]["from"] == "none"`, `tool_names(server, lock)` returns `[]` (falsy), so `(tool_names(server, lock) or [name])` evaluates to `[name]` and `name not in ...` is `False`. And if a tool in `PROTECTED_REVIEWED` is also flagged in `server["flagged"]` (in `tools` or in `changes`), `check_against` does not report that the `PROTECTED_REVIEWED` exemption is redundant/contradicted.
  2. Neither `check_structure` nor `check_against` rejects a tool that is listed in `flagged[].tools` under two different areas of the same server, listed in two `knowledge` entries of the same server, or listed in both `flagged[].tools` ("never called") and `flagged[].changes` ("never made through `` `tool` ``").
- Suggested replacement: In `scripts/toolchain_catalog.py` (`check_against`), check `PROTECTED_REVIEWED` with `names = tool_names(server, lock) if server is not None else []` (where `names is None` only when a lock contract is uncaptured) and also report if `(sid, name)` is already flagged in `server["flagged"]`; in the per-server loop, report any tool name duplicated across `knowledge` entries, across `flagged[].tools` entries, or present in both `flagged[].tools` and backticked names of `flagged[].changes`.

F2. Low. `catalog_quotes.py` (`lists` and `check`) does not verify that every `from: "page"` server/group in `catalog.json` is in `LISTS` or that `NOT_ON_THE_PAGE` tools remain in `catalog.json`, and `check` does not enforce the 12-word quote limit.
- File and line: `verification/tools/catalog_quotes.py` lines 155–180 (`check`) and 245–274 (`lists`).
- Quote: `mine = [n for n in mine if n not in`
- Details:
  1. `lists()` iterates over the hardcoded `LISTS` table without checking that every server in `catalog["servers"]` with `tools["from"] == "page"` (and every named `set` in its `tools["groups"]`) is represented in `union`, so a newly added `from: "page"` server or toolset omitted from `LISTS` silently passes `lists()`.
  2. Line 260 (`mine = [n for n in mine if n not in NOT_ON_THE_PAGE.get(sid, set())]`) strips `NOT_ON_THE_PAGE[sid]` without checking that those tools are actually present in `mine` and absent from `found`; if `accept_eula` or `create_connection_ui` were removed from `catalog.json`, `lists()` would still print `OK`.
  3. `check()` does not check the 12-word limit stated in the module docstring and checks `...`-separated fragments independently across all cited pages of the server (`any(needle in text for text in own)`).
- Suggested replacement: In `verification/tools/catalog_quotes.py` (`lists`), verify that `{(s["id"], g.get("set")) for s in catalog["servers"] if s["tools"]["from"] == "page" for g in s["tools"]["groups"]} == set(union)` and that `NOT_ON_THE_PAGE.get(sid, set()) <= set(mine) - set(found)`; in `check`, flag quotes with more than 12 words (`len([w for f in fragments for w in f.split()]) > 12`) and require all fragments of a quote to appear in order on at least one single cited page.
