# Design review: GPT 6.1 Sol (lens: architecture and feasibility)

Date 2026-10-30. Reviewer: GPT 6.1 Sol (`rubber-duck` agent, read-only, web access). Reviewed `04-design.md` v0.1 against the requirements, decision register, landscape digest and verification results. Transcribed by the orchestrator in condensed form from the reviewer's inline reply.

Result: 20 findings. 0 CRITICAL, 18 HIGH, 2 MEDIUM. The reviewer states that HIGH findings block Phase 1 and MEDIUM findings must be resolved before Phase 2.

## What the reviewer found strong

- Git as source of truth, with workspaces downstream.
- A deterministic outer workflow with bounded agent steps.
- Separate proposer, publisher and Fabric execution identities.
- Synthetic data, a dedicated capacity and static checks first.
- Independent oracle authorship, and verifier blocks that cannot override gates.
- A single-unit T0 and T1 pilot, explicit escalation, and human-only merge and promotion.

## Reviewer's top five changes before Phase 0

1. Define the immutable execution manifest and a constrained test format.
2. Specify authoritative state, ambiguous-outcome recovery, leases and the crash-test matrix.
3. Resolve runner-principal isolation and concrete Git approval, push and merge permissions.
4. Choose one initial deployment mechanism and define baseline and current-merge validation.
5. Rewrite phase exits so authentication, pinning, model boundaries, budgets and retained evidence are prerequisites.

## Questions the reviewer says the design cannot answer

- Which exact pilot model features and data-source types must work?
- Which tenant and capacity permissions and runner-principal lifecycle will administrators approve?
- Who supplies a sufficiently complete consumer inventory for T2 changes?
- Are unattended data-agent evaluation and ontology functional tests supported? (Unsure.)
- Who are the independent approvers, and what review and preview lifetime can they support?
- What spending ceiling, overshoot allowance and provider-retention policy are authorized?
