## Top 5 corrections

1. Tabular Editor `te` docs disagree on expiry: Command-line-Options says 2026-10-31; te-cli.html and the CI page say 2026-12-31. Either way it is Limited Public Preview and not for production CI. TE2 `TabularEditor.exe` is the stable path and needs no TE3 license.
2. AutoGen and Continue are not GitHub-archived. AutoGen's README says archived, but the API flag is false and the 2026-10-28 commit only added that notice. Continue's README says read-only, while `pushed_at` is 2026-10-30.
3. Vendors do not uniformly gate agent edits with branch, review, and human merge. Omni's Auto mode applies changes immediately. Maia's "guidance, not hard-coded rules" sentence is real. ThoughtSpot's page is TML Git integration, not an agent merge gate.
4. Genie Code auto-approve is labeled Recommended, not documented as the default. Scheduled runs do always auto-approve with the creator's permissions, and the docs say it is not a security boundary. dbt Wizard agent-authorship disclosure was not on the cited release notes.
5. Microsoft Agent Framework has a `ClaudeAgent` wrapper, but that package is installed with `--pre`, and the 2026-10-22 provider table has no xAI/Grok provider. FabricIQ "service principals unsupported" and hosted Core "delegated-user" OAuth are not stated on the cited pages.
