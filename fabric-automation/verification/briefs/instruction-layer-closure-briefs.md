## Shared preamble (read first, then your slice)

You are doing a CLOSURE CHECK of ONE piece of an open-source project: the INSTRUCTION LAYER of a "Fabric Code Factory" (design and toolchain in the public repository https://github.com/apkola29/fabric, folder `fabric-automation`). The factory turns a natural-language requirement for Microsoft Fabric and Power BI items into a verified draft pull request. People and unattended jobs run AI agents (Claude, GPT, Gemini and Grok models, under Copilot CLI, VS Code, Claude Code or Gemini CLI). The toolchain kit pins the agent skills and MCP servers that those agents may load. The instruction layer is the text that tells an agent what it has, where its knowledge comes from, how sign-in works, what to do when a server does not answer, and how to look for newer skills and servers.

WHAT THE OWNER ASKED FOR (paraphrased; this is the yardstick):
